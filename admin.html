Remember this on this device (so you don't re-enter it)

For your safety, a remembered login auto-clears after 60 days of not opening this panel — you'll just need to paste your token back in. You can also clear it immediately anytime with "Forget device" up top.

Don't have a token? Here's how to make one
  1. Go to GitHub → click your avatar → Settings → Developer settings → Fine-grained personal access tokens → Generate new token.
  2. Give it any name, like control panel.
  3. Under Repository access, choose Only select repositories and pick your site's repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Click Generate token and copy it (starts with github_pat_) — paste it into the Access Token field above.
